Loremem 云服务是托管版 Lore，地址为 `https://app.loremem.com`。登录之后，记忆按项目存放，创建令牌、接入 Agent 即可使用；记忆模型与自托管服务器完全相同。

## 登录

在 `https://app.loremem.com/login` 使用 GitHub 或 Google 登录。由管理员创建的账户还可以使用邮箱和密码登录。Loremem 云服务不提供公开的邮箱注册。

首次登录会自动创建一个个人组织和一个默认项目。

## 组织与项目

一个组织包含多个项目。**项目** 是一个独立的记忆空间，拥有自己的记忆图谱、召回分析、Dream 运行记录、设置、令牌和技能。

使用控制台顶部的组织和项目切换器，即可切换当前所在的位置。如果某个产品或代码库的记忆需要彼此隔离，请为它单独创建一个项目。

## 令牌

每个令牌只属于一个项目。创建方法如下：

1. 打开 **安装** 页面，填写 **令牌备注**，例如 `laptop`。备注只用于记录令牌在哪里使用。
2. 选择 **创建令牌**。
3. 复制令牌和安装命令。两者都只显示一次。

在 **令牌** 页面（`/apitokens`）管理令牌。该页面列出每个令牌的名称、前缀、末四位、状态和最后使用时间。选择 **撤销** 可停用某个令牌。令牌的格式类似 `lm_your_token`。

## 接入 Agent

**安装** 页面会显示一条安装命令，其中已填入你的 API 地址和新令牌：

```bash
npx @loremem/cli install --base-url https://api.loremem.com --api-token lm_your_token
```

在每台使用 Agent 的机器上运行该命令，然后重启各个 Agent 运行时。CLI 会连接它在这台机器上发现的运行时。如需自行选择，请传入 `--channels`。

## 模型

每个项目在 **设置 → 模型** 中选择两个预配置的模型配置：用于召回的嵌入模型配置，以及用于 Dream 的运行时 LLM 配置。你无需填写 API 密钥。

更换嵌入模型配置会重建项目的视图和召回索引，并消耗模型额度。只更换运行时 LLM 配置会立即保存，不会重建索引。

## 与自托管的异同

记忆模型、召回、Dream 和备份设置在两种部署中的工作方式相同。下表列出了不同之处：

| 方面 | 自托管服务器 | Loremem 云服务 |
| --- | --- | --- |
| 记忆模型 | 节点、路径、触发条件、术语、优先级和历史 | 相同 |
| 召回 | 你自己的嵌入端点和召回设置 | 设置相同，使用项目的嵌入模型配置 |
| Dream | 使用你的 View LLM 运行 | 使用项目的运行时 LLM 配置运行。定时计划按服务时钟执行。 |
| 备份 | 本地文件和 WebDAV。在 **设置** 中执行备份、导出和恢复 | 定时、保留和 WebDAV 设置相同。备份标签页没有运行、导出或恢复按钮。 |
| 技能 | 不可用 | 可用。参见 [技能](/documents/skills)。 |
| 组织与项目 | 每台服务器只有一个记忆空间 | 组织包含项目，每个项目彼此独立 |
| 模型 | 你需要填写嵌入和 View LLM 的端点与密钥 | 预配置的模型配置，无需填写 API 密钥 |

## API 与 MCP 端点

- API 基础地址：`https://api.loremem.com`
- 通用 MCP 端点：`https://api.loremem.com/api/mcp?client_type=mcp`，请求头为 `Authorization: Bearer lm_your_token`

## 安全提示

- 为每台机器，或为每个使用位置，分别创建一个令牌，并在备注中写明它的用途。
- 撤销所有不再使用的令牌。在 **令牌** 页面查看 **最后使用** 时间，找出闲置的令牌。
- 永远不要把令牌粘贴到记忆、技能、提示词或共享聊天中。
- CLI 只会通过 HTTPS 发送令牌，或通过明文 HTTP 发送到 `localhost` 等回环地址。

要把自托管服务器上的记忆迁入项目，请参见 [导入自托管备份](/documents/cloud/import-self-hosted-backup)。
