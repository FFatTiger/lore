了解 Web 控制台的每个页面各有什么用途，以及什么时候该用控制台，而不是直接问你的 Agent。自托管和 Loremem 云服务的大部分页面相同，表格中会注明差异。

## 自托管控制台

在 `http://127.0.0.1:18901` 打开控制台。顶部导航包括 **记忆**、**召回**、**分析**、**Dream** 和 **设置**。首次初始化页面位于 `/setup`。

| 页面 | 路径 | 可以做什么 |
| --- | --- | --- |
| 记忆 | `/memory` | 浏览域和节点。编辑内容、路径、优先级、触发条件和术语。在 `/memory/history` 打开节点历史，查看它的事件，并把节点回滚到较早的事件。 |
| 召回 | `/recall` | 运行查询，查看流水线各阶段、候选记忆和分数。 |
| 分析 | `/recall/drilldown` | 查看查询数、展示数和采用数，以及按运行时的细分。打开某次查询可以查看详情。 |
| Dream | `/dream` | 运行 Dream，阅读日记，通过或忽略每项变更，并回滚一次运行。 |
| 设置 | `/settings` | 修改通用（生命周期和提示文本）、召回、模型服务和维护（策略、Dream、备份）相关设置。在“备份操作”中手动备份和恢复。 |
| 首次初始化 | `/setup` | 完成嵌入模型、View LLM、启动记忆和渠道 Agent 记忆的首次设置。 |

## Loremem 云服务控制台

在 `https://app.loremem.com` 打开控制台。项目切换器和组织切换器位于顶部。记忆、召回、Dream、设置、令牌和技能都属于当前选中的项目。

| 页面 | 可以做什么 |
| --- | --- |
| 概览 | 查看项目的召回分析：合并、展示、查询和采用。查看渠道概览和最近查询。概览页还有一张卡片，指向 **安装** 和 **测试召回**。 |
| 安装 | 创建项目令牌，复制安装命令。在“开源版备份导入”下导入自托管备份。 |
| 令牌 | 查看所有令牌的前缀、末四位、状态和最近使用时间。撤销令牌。 |
| 记忆 | 浏览、编辑和移动节点，创建子节点。打开节点历史，查看每次变更及其差异。 |
| 召回 | 在召回工作台运行查询。打开某次查询，查看每个流水线阶段和候选记忆。 |
| Dream | 运行 Dream，阅读日记，批准或标记为已知晓每项变更，并回滚最近一次运行。 |
| 技能 | 新建技能，或上传 `.skill` 和 `.zip` 技能包。编辑文件，设置 **启用**、**可见范围** 和 **调用方式**，或归档技能。 |
| 设置 | 通过六个标签页调整项目行为：**偏好**（召回行为）、**生命周期**（使用规则和提示文本）、**策略**（优先级容量和触发条件检查）、**Dream**（计划）、**模型**（嵌入模型配置和运行时 LLM 配置）和 **备份**。 |

超级管理员还能看到 **用户** 和 **诊断**，以及 **系统** 和 **模型配置** 两个设置标签页。

## 召回分析术语

| 术语 | 含义 |
| --- | --- |
| 合并（Merged） | 召回流水线产出的排序候选记忆。 |
| 展示（Shown） | 注入提示词的记忆。 |
| 查询（Queries） | 召回运行的次数。 |
| 采用（Used） | Agent 带着召回 ID 打开过的记忆。 |
| 区分度（Separation） | 分数区分“被采用”和“未被采用”记忆的能力。 |

## 何时使用控制台

- **查看 Agent 知道什么。** 打开 Agent 引用的节点，或在记忆中搜索某个词。
- **排查召回问题。** 在召回中运行同样的查询，把候选和分数与 Agent 收到的内容对比。
- **审查 Dream。** 每次运行后阅读日记，然后批准或标记每项变更。
- **统一调整所有 Agent 的行为。** 在一处修改指导文本、启动节点和召回设置。
- **接入 Agent。** 在 **安装** 页创建令牌，复制安装命令。参见[快速开始](/documents/quickstart)。

## 日常规则

Agent 使用了过时的上下文时，修正记忆本身：更新内容，收紧触发条件，或补充它本该匹配到的术语。然后在召回中运行同样的查询，确认节点已能被找到。不要把规则重新抄回 `CLAUDE.md` 或 `AGENTS.md`，那只会让你想消除的不一致重新出现。
