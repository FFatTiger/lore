查阅 Lore 保存的每一项运行时设置，包括键名、默认值和作用。这些设置保存在数据库中，应在控制台或通过 API 修改，而不是在 `.env` 中修改。部署环境变量列在[服务器配置](/documents/self-hosting/configuration)中。

## 如何修改设置

- **自托管：** 在 Web 控制台中打开 `/settings`，或发送带有 `patch` 对象的 `PUT /api/settings` 请求。每个值都要使用对应的 JSON 类型：数字和布尔值不加引号，字符串加引号。

  ```bash
  curl -fsS -X PUT http://127.0.0.1:18901/api/settings \
    -H 'content-type: application/json' \
    -H 'authorization: Bearer lm_your_token' \
    --data '{"patch": {"recall.display.min_display_score": 0.6, "dream.cron": "0 2 * * *"}}'
  ```

- **Loremem 云服务：** 打开项目的**设置**页面。标签页包括**偏好**、**生命周期**、**策略**、**Dream**、**模型**和**备份**。在**模型**标签页中，你可以选择 embedding 配置和运行时 LLM 配置。云服务不需要你填写 API key。
- **密钥：** `embedding.api_key`、`view_llm.api_key` 和 `backup.webdav.password` 只写不读。Lore 不会再次显示已保存的值，只会显示是否已设置。如需替换，请发送新的值。

## 召回

### 显示与保护

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `recall.display.min_display_score` | `0.60` | 得分低于该值的候选不会注入提示词。取值范围 `0` 到 `1`。 |
| `recall.display.max_display_items` | `3` | 每次召回最多注入的记忆条数。取值范围 `1` 到 `20`。 |
| `recall.safety.max_query_chars` | `200` | 对于很长的提示，召回只使用前 N 个字符，并注明已截断。取值范围 `50` 到 `2000`。 |
| `recall.safety.timeout_ms` | `2000` | 超过这个毫秒数，召回会跳过并附带提示。在 Loremem 云服务中作用于提问召回；在自托管服务器上作用于召回 API，Agent 钩子使用各自的超时。取值范围 `500` 到 `30000`。 |

### 权重

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `recall.weights.w_exact` | `0.30` | 路径、术语和查询词精确匹配的权重。 |
| `recall.weights.w_glossary_semantic` | `0.25` | 查询与术语之间语义相似度的权重。 |
| `recall.weights.w_dense` | `0.30` | 稠密 embedding 相似度的权重。 |
| `recall.weights.w_lexical` | `0.03` | 全文（词法）匹配的权重。 |

### 加分

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `recall.bonus.priority_base` | `0.05` | 优先级 0 的加分。优先级每增加 1，加分减少 `priority_step`。 |
| `recall.bonus.priority_step` | `0.01` | 优先级每增加 1，减少的加分。 |
| `recall.bonus.multi_view_step` | `0.015` | 每匹配一种额外的视图类型（gist 或 question）所增加的加分。 |
| `recall.bonus.multi_view_cap` | `0.05` | 多视图加分的上限。 |

### 新近度

| 键 | 默认值 | 作用 |
| --- | --- | --- |
| `recall.recency.enabled` | `true` | 给最近更新的记忆加分，给较早的记忆减少加分。设为 `false` 则使用早期版本的评分方式。 |
| `recall.recency.half_life_days` | `180` | 新近度加分降至最大值一半所需的天数。取值范围 `7` 到 `3650`。 |
| `recall.recency.max_bonus` | `0.04` | 刚刚更新的记忆可获得的最大新近度加分。取值范围 `0` 到 `0.3`。 |
| `recall.recency.priority_exempt` | `1` | 优先级不高于该值的记忆永不衰减。设为 `-1` 则所有记忆都会衰减。 |

## 提示词

提示词的键是很长的模板。下面每一组只占一行，而不是逐个列出每个键。

| 分组 | 键数量 | 用途 |
| --- | --- | --- |
| `prompts.view_generation.system` | 1 | 生成 gist 视图和 question 视图的系统提示词 |
| `prompts.boot_draft.*` | 13 | 起草启动记忆：一个系统提示词，外加共享节点、每个 `client_<runtime>` 节点的说明，以及额外约束 |
| `prompts.dream.*` | 7 | Dream 的系统提示词、日记改写提示词，以及每个阶段的提示词：诊断、规划、预检、应用和审计 |

提示词中包含占位符，例如 `{{instructions}}`、`{{client_type}}`、`{{guidance}}`、`{{plan_json}}` 和 `{{apply}}`。请保留每个提示词所需的占位符。只有当你清楚每个阶段如何使用其输出时，才应修改 Dream 的提示词。
