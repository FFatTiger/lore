技能（Skill）是 Loremem 云服务为 Agent 提供的可复用指令包。每个技能是一个带版本的包，Agent 在会话开始时就能看到它，需要时再加载。技能仅在 Loremem 云服务中可用，开源服务器没有技能功能。

## 技能是什么

技能是一个带版本的包。它唯一必需的文件是 `SKILL.md`。你还可以添加辅助文件，例如脚本、参考文档或模板。每次保存都会创建该包的一个新版本。

`SKILL.md` 以 YAML 前置元数据（frontmatter）开头，其中给出技能的 `name` 和 `description`。前置元数据之后的文本是具体指令：

```text
---
name: release-notes
description: Write release notes for checkout-api from merged pull requests. Use when the user asks for release notes or a changelog.
---

# Release notes

1. List pull requests merged since the last tag.
2. Group them under Added, Changed, and Fixed.
```

这些字段的规则如下：

- 名称只能使用小写字母、数字和连字符，长度为 1 到 64 个字符，且不能以连字符开头或结尾。
- 前置元数据中的 `name` 就是技能名称，创建之后不能修改。
- 描述最多 1,024 个字符。Agent 依据它来判断何时加载该技能。

## Agent 如何找到并加载技能

1. 会话开始时，Agent 会收到一个 `<available_skills>` 列表。每一项显示技能的名称、描述和 `skill_id`。设置为 **仅用户触发** 的技能不会出现在列表中。列表最多容纳 8,000 个字符。如果技能太多放不下，Agent 会被告知还有多少个技能，并被要求调用 `lore_skill_list`。
2. 当任务与某个技能的描述匹配时，Agent 会用 `skill_id` 调用 `lore_skill_get`。
3. `lore_skill_get` 返回完整的 `SKILL.md`，以及该技能本地目录的绝对路径。

本地副本位于 `~/.lore/skill-artifacts/<project-id>/<skill-name>/`。如果设置了 `LORE_HOME`，Lore 会使用该目录而不是 `~/.lore`。Agent 第一次加载某个技能时，Lore 会下载它；版本变化时，Lore 会刷新副本。会话开始时，Lore 不会下载技能。

## 自己调用技能

在提示词中输入 `$` 加技能名称，例如 `$release-notes`。即使技能设置为 **仅用户触发**，Lore 也会为这次请求加载它。一条提示最多可以调用三个技能。

## 可见范围与调用方式

每个技能有三项设置：

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| 启用 | 开或关 | 关闭后，Agent 不会看到或加载该技能。 |
| 可见范围 | 所有 Agent，或单个运行时 | 限定在某个运行时的技能，只对该运行时可见。 |
| 调用方式 | Agent 与用户（默认），或仅用户触发 | **仅用户触发** 会对 Agent 隐藏该技能，只有用户输入 `$名称` 时才运行。它等同于在 `SKILL.md` 中设置 `disable-model-invocation: true`。 |

## 本地副本与文件权限

Lore 在本地副本中管理两类文件：

- **托管文件**来自服务器。Lore 会把它们设为只读（在 Linux 和 macOS 上为 `0444`）。如果你编辑了其中一个文件，下一次 `lore_skill_get` 会把它恢复。
- **本地文件**是技能目录中的其他文件，例如 Agent 在那里写入的输出。该目录保持可写。Lore 从不上传本地文件，并且它们在更新后会保留。

有新版本到达时，Lore 只更新托管文件。如果某个本地文件与新版本中的托管路径冲突，更新会失败，现有副本保持不变。

Lore 不会为脚本设置可执行权限，因此请通过解释器运行脚本，例如 `python3 scripts/convert.py`。

> [!WARNING]
> 每个加载技能的 Agent 都会下载完整的技能包，包括所有文件。不要在技能中放入密钥、令牌或私有主机名。

## 技能工具

| 工具 | 用途 |
| --- | --- |
| `lore_skill_list` | 列出当前项目中的技能。 |
| `lore_skill_search` | 按查询词搜索技能。 |
| `lore_skill_get` | 下载或刷新本地副本，并返回 `SKILL.md` 和技能目录。 |
| `lore_skill_create` | 用名称和文件列表创建技能。 |
| `lore_skill_update` | 更新技能。需要 `expected_version`。 |
| `lore_skill_delete` | 归档技能。 |
| `lore_skill_status` | 报告每个本地副本是就绪、缺失、过期、被篡改、未托管还是无效。该工具只读。 |

有关控制台以及创建、更新和归档的操作，请参见 [创建与管理技能](/documents/skills/managing-skills)。

## 运行时

技能适用于 Claude Code、Codex、OpenCode、Pi、OpenClaw、Hermes 和 ZCode。通过通用 MCP（`client_type=mcp`）连接的客户端不会获得技能。

只有当服务器报告支持技能时，CLI 才会启用技能工具。Loremem 云服务支持技能，开源服务器不支持。
