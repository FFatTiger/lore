你可以在 Loremem 云服务控制台的 **技能** 页面创建和管理技能，也可以让 Agent 通过技能工具创建和更新技能。

## 创建技能

1. 打开 **技能** 页面，选择 **新建技能**。
2. 填写 **名称**。只能使用小写字母、数字和连字符，最多 64 个字符，例如 `research-notes`。创建之后不能修改名称。
3. 填写 **描述**。Agent 会依据这段文字判断何时加载该技能，因此请写清它做什么、何时使用。上限为 1,024 个字符。
4. 选择 **可见范围**：所有 Agent，或单个运行时。
5. 如果希望 Agent 永远不要自行加载该技能，请开启 **仅用户触发**。
6. 选择 **创建技能**。

新技能会以一个 `SKILL.md` 开始。它的前置元数据中包含名称和描述，正文中是一个标题和作为占位文字的描述。打开 `SKILL.md`，把正文替换为你的指令。

## 上传技能包

选择 **上传技能包**，从文件导入技能：

- `.skill` 文件只包含一个技能，其 `SKILL.md` 位于压缩包根目录，或位于某一个顶层文件夹中。
- `.zip` 文件可以包含多个技能。每个包含 `SKILL.md` 的文件夹都会成为一个技能。

每个导入技能的名称取自其 `SKILL.md` 中的 `name`，而不是文件名或文件夹名。**可见范围** 的选择适用于本次上传的每个技能。

上传完成后，每个技能会显示 **已创建**、**已存在** 或 **失败**。选择 **打开** 可查看该技能。

Lore 强制执行以下限制：

| 限制 | 数值 |
| --- | --- |
| 上传文件 | 25 MiB |
| 每个技能的文件数 | 256 |
| 单个文件大小 | 5 MiB |
| 单个技能的大小 | 10 MiB |
| 单次上传解压后的内容 | 40 MiB |

## 编辑文件与版本

打开技能，即可在浏览器中编辑 `SKILL.md` 和其他文件。

- 选择 **新建文件…** 可添加文本文件。请使用相对路径，例如 `references/guide.md`。路径不能包含空段、`.` 或 `..`。
- 选择 **删除此文件** 可移除文件。在保存之前，可以选择 **恢复** 撤销删除。
- 二进制文件不能在浏览器中编辑。如需替换，请重新上传技能包。
- 你的修改会保持为 **有未保存的修改**，直到你选择 **保存**。每次保存都会创建新版本，例如 `v3`。选择 **放弃** 可丢弃未保存的修改。

如果你在编辑期间有人保存了更新的版本，Lore 会显示 **该技能已在其他地方更新**。你的修改仍会留在屏幕上。选择 **在最新版本上保存我的修改**，把它们叠加到最新版本之上；或选择 **放弃我的修改**，加载最新版本。

当 `SKILL.md` 有未保存的修改时，不能更改技能的设置。请先保存或放弃这些修改。

## 设置

打开技能，选择 **设置**。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| 启用 | 开或关 | 关闭后，Agent 不再看到或加载该技能。 |
| 可见范围 | 所有 Agent，或单个 Agent | 把技能限定在某个运行时。 |
| 调用方式 | Agent 与用户，或仅用户触发 | **仅用户触发** 会对 Agent 隐藏该技能，只有用户输入 `$名称` 时才运行。 |

调用方式以 `disable-model-invocation: true` 的形式保存在 `SKILL.md` 中。在控制台中修改它会更新文件中的那一行；编辑该行也会改变控制台中的设置。选择 **复制触发词** 可复制 `$名称` 文本。

## 归档技能

当不再需要任何 Agent 使用某个技能时，请归档它。依次选择 **归档技能**、**归档…**，然后用 **确认归档** 确认。

> [!WARNING]
> 归档不可撤销。Agent 将无法再找到或加载该技能，该名称也无法再次使用，而 Agent 机器上已有的副本会保留在原处。

## 让 Agent 创建和更新技能

拥有技能工具的 Agent 也可以管理技能：

- `lore_skill_create` 接受 `name`、必须包含 `SKILL.md` 的 `files` 列表，以及可选的 `enabled` 标志（默认为 `true`）。新技能不会自动复制到 Agent 的机器上，直到 Agent 调用 `lore_skill_get`。
- `lore_skill_update` 接受 `skill_id` 和 `expected_version`，即 Agent 上一次读取的版本号。它还可以设置 `enabled`、创建或替换文件（`upsert_files`），以及删除路径（`delete_paths`）。如果技能已经更新到更新的版本，更新会因版本冲突而失败。此时 Agent 应通过 `lore_skill_get` 读取最新版本，然后重试。名称不能修改。
- `lore_skill_delete` 会归档技能，效果与 **归档技能** 相同。

关于这些工具的返回内容，以及 Agent 在会话开始时如何看到技能，请参见 [技能](/documents/skills)。
